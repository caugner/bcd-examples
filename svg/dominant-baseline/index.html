dominant-baseline text-top and text-bottom

Each box has a red line at y=50. In the first box (no dominant-baseline), the text sits on the line. If a box is supported, the text moves relative to the line, as described below. If it looks the same as the first box, the value is ignored.

text-top: the top of the text should touch the red line, so the text should hang below it.

Above: no value (reference), dominant-baseline="text-top" attribute, dominant-baseline: text-top CSS property.

text-bottom: the bottom of the text, including the descender of "g", should touch the red line, so the letters "Hx" should sit slightly above the line.

Above: no value (reference), dominant-baseline="text-bottom" attribute, dominant-baseline: text-bottom CSS property.

Control: dominant-baseline="middle" is supported everywhere, so the text should be centered on the line.
