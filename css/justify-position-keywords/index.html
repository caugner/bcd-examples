start, end, left, right in alignment properties

Each row has a 300px box with a 40px blue item. The dashed outline marks where the item should be. Green PASS means the item sits at the expected edge and that edge differs from the default position, so the keyword has an observable effect. Red FAIL means the keyword was parsed and ignored, or is not supported. Grey means the expected position equals the default, so the row gives no signal. parse shows the CSS.supports() result.
